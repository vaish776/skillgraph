# SkillGraph

Graph-powered talent discovery application using FastAPI and CognoDB.

## Tech Stack

- Python
- FastAPI
- CognoDB
- Cypher
- HTML
- CSS
- JavaScript

## Features

- Explore people and their skills
- View individual profiles
- Explore projects
- Graph-based skill relationships
- Project-to-person matching
- REST API with FastAPI
- CognoDB graph database integration
